# Boletín Diario de Data Analytics

*Miércoles, 30 de septiembre de 2026*

## 1. Noticias Destacadas en España y Europa

- **FabCon + SQLCon 2026 se celebra en Barcelona con más de 5.000 asistentes de 71 países.** Microsoft reunió por primera vez su conferencia europea de Fabric junto con SQLCon en el CCIB de Barcelona (28 sept.–1 oct.). En el keynote de apertura, Arun Ulag, Amir Netz y Shireesh Thota presentaron un paquete de novedades para Microsoft Fabric, Power BI, OneLake y Azure SQL centradas en construir una "base de datos de confianza" para IA empresarial: Fabric IQ integrado en Copilot (disponibilidad general), un nuevo Database Hub en Fabric (vista previa) para gestionar SQL Server, Azure SQL, PostgreSQL y Cosmos DB desde un panel único, y la disponibilidad general de SQL Server on Azure Local.
  Fuente: https://azure.microsoft.com/en-us/blog/fabcon-and-sqlcon-2026-in-barcelona-building-the-data-foundation-for-microsoft-copilot-and-agents/

- **Daivio, nueva solución israelí de analítica con IA, se lanza para Microsoft Fabric coincidiendo con FabCon Barcelona.** DATA AI ANALYSIS LTD (Tel Aviv) ha publicado Daivio en el Microsoft Fabric Workload Hub y en Microsoft Marketplace. La herramienta permite perfilar, limpiar (18 transformaciones con un clic) y analizar datos almacenados en OneLake mediante preguntas en lenguaje natural, devolviendo la consulta SQL generada, la tabla de resultados y un gráfico, sin salir del workspace de Fabric. Incluye plan gratuito, Pro (pago por minuto de procesamiento) y Enterprise.
  Fuente: https://www.globenewswire.com/news-release/2026/09/29/3370412/0/es/daivio-lanza-una-soluci%C3%B3n-de-an%C3%A1lisis-de-datos-basada-en-ia-para-microsoft-fabric.html

## 2. Tendencias Globales y Nuevas Herramientas

- **Power BI Desktop estrena creación de apps mediante lenguaje natural ("Agentic App Creation").** Anunciada en FabCon Barcelona y con lanzamiento en vista previa en las próximas semanas, permite describir en texto libre la aplicación deseada y generarla directamente en Power BI Desktop, con hasta 1 GB por app sin coste adicional para clientes de Power BI Pro, Premium Per User y capacidad Fabric. Se suma la disponibilidad general de los índices vectoriales DiskANN en Azure SQL Hyperscale, clave para búsquedas semánticas a gran escala.
  Fuente: https://azure.microsoft.com/en-us/blog/fabcon-and-sqlcon-2026-in-barcelona-building-the-data-foundation-for-microsoft-copilot-and-agents/

- **BigQuery: el Data Engineering Agent pasa a disponibilidad general integrado con BigQuery Graph.** Google ha llevado a GA la integración de su agente de IA para ingeniería de datos con BigQuery Graph, que añade contexto entre el esquema de origen y destino y mejora la precisión del mapeo de esquemas en pipelines de datos, reduciendo el trabajo manual en tareas de ETL.
  Fuente: https://docs.cloud.google.com/bigquery/docs/release-notes

- **La extensión de Looker para VS Code alcanza disponibilidad general con desarrollo asistido por IA vía MCP.** Google Cloud ha publicado en GA la extensión que permite desarrollo local de LookML con "vibe coding" asistido por IA usando el Model Context Protocol, incorporando un asistente de incorporación interactivo, sincronización mejorada entre ramas Git locales y el modo de desarrollo de Looker, y soporte OAuth con el IDE Kiro.
  Fuente: https://docs.cloud.google.com/looker/docs/release-notes/
