## 2. Tendencias Globales y Nuevas Herramientas

### Python y SQL

- **DuckDB publica «Importing Data using Java Table Functions» (5 de octubre de 2026).** La entrada del blog de ingeniería de DuckDB explica cómo importar datos mediante funciones de tabla escritas en Java, ampliando las vías de integración del motor analítico embebido con ecosistemas empresariales.
  https://duckdb.org/2026/10/05/import-data-with-java.html

- **DuckDB: agregaciones de cadenas más rápidas con tablas de dimensión (2 de octubre de 2026).** El equipo de DuckDB detalla una técnica para acelerar las agregaciones sobre columnas de texto usando tablas de dimensión, una mejora relevante de rendimiento para cargas analíticas en SQL.
  https://duckdb.org/2026/10/02/dimension-tables.html

- **DuckDB 1.5.6 y consultas SQL en lenguaje natural con Jev (28 y 29 de septiembre de 2026).** DuckDB anunció la versión 1.5.6 y presentó Jev, una forma de expresar condiciones SQL en inglés sencillo, además de la consulta directa de datasets de Hugging Face (25 de septiembre).
  https://duckdb.org/2026/09/28/announcing-duckdb-156.html

- **pandas 3.0.6 es la primera versión 3.0 compatible con Python 3.15 (17 de septiembre de 2026).** Corrige problemas en lectura de CSV, gráficos y cadenas categóricas. PostgreSQL 18.6 llegó el 13 de agosto de 2026 junto con la beta 3 de PostgreSQL 19.
  https://pandas.pydata.org/docs/whatsnew/index.html

### IA y software emergente (vigilancia disruptiva para BI)

- **El BI se vuelve agéntico: agentes de IA sustituyen a los dashboards estáticos (tendencia de 2026).** Tableau Next propone agentes que anticipan insights, Power BI incorpora agentes de IA en la capa analítica desde su actualización de junio y Amplitude lanzó agentes de analítica para equipos de producto.
