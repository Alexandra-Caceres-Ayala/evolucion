## 2. Tendencias Globales y Nuevas Herramientas

### Python y SQL

- **Databricks añade en beta un almacén SQL administrado para las trazas de MLflow en Unity Catalog (2 de noviembre de 2026).** La nueva función «Managed Warehouse for MLflow» permite consultar desde la interfaz de MLflow las trazas almacenadas en Unity Catalog sin tener que elegir manualmente un almacén SQL: MLflow ejecuta las consultas sobre un warehouse SQL que crea automáticamente en el workspace cuando está disponible, o sobre cómputo serverless en caso contrario. Los administradores pueden activarlo desde la página de Previews, lo que simplifica el gobierno y el coste de analizar con SQL la observabilidad de modelos de IA junto al resto de datos corporativos.
  https://docs.databricks.com/gcp/ja/release-notes/product/2026/november

- **Microsoft Fabric incorpora Sail, un motor de ejecución compatible con Spark escrito en Rust, para leer y escribir directamente en OneLake (anunciado el 29 de octubre de 2026).** El conector de catálogo de Sail para OneLake permite operar sobre las tablas lakehouse de Microsoft Fabric usando el endpoint Iceberg REST (o, alternativamente, uno al estilo Unity Catalog), autenticando con Microsoft Entra, de modo que cargas de trabajo compatibles con la API de Spark pueden ejecutarse con el rendimiento de un motor nativo en Rust en lugar de la JVM tradicional.
  https://docs.lakesail.com/sail/main/guide/catalog/onelake.html

### IA y software emergente (vigilancia disruptiva para BI)

- **Microsoft presenta en vista previa el agente de ingeniería de datos para Fabric, «Project Osmos» (anunciado el 29 de octubre de 2026).** El agente permite describir en lenguaje natural un resultado completo de ingeniería de datos —por ejemplo, construir una arquitectura medallion o modelar datos de Dynamics 365, SAP, NetSuite o Salesforce— y lo ejecuta como una tarea persistente sobre Fabric SparkCore, encargándose de la planificación, la secuenciación y la validación incluso con el equipo del usuario apagado; se invoca desde agentes locales como GitHub Copilot CLI, Claude Code o Codex a través del complemento Skills for Fabric. Está en preview, sin SLA y no recomendado para producción. Tendencia disruptiva para BI: desplaza el rol del ingeniero de datos de «escribir el pipeline» a «describir el resultado y supervisar al agente», llevando a la ingeniería de datos el mismo flujo de trabajo agéntico que ya se usa en programación.
  https://learn.microsoft.com/en-us/fabric/data-engineering/data-engineering-agent-get-started
